# Feature checks

Each row says how to reach a feature, what it should do, and how to check it. `scripts/verify --list` names every target.

Your Apps: `scripts/verify your-apps` runs the focused type, lint, request, permission, password and UI component checks. Add `--ui` to drive both 1440px and 1180px windows on the sample two-person stack. The browser fixtures answer website and publishing requests locally; these checks do not claim vendor deployment success. Bops Cloud's part (SharedApp.github) is in `cloud/test/core-members.test.ts`, which needs the test database.
